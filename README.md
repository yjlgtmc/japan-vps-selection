## 原生IP、广播IP、ISP住宅IP，买错就白花钱

这是日本 VPS 最容易踩的坑，也是最值得花五分钟搞懂的部分。

**原生 IP** 指 IP 段在 ARIN、RIPE 这类机构注册时归属地就在日本，不是靠 BGP 广播"借"到日本来的。查 IP 属性时显示日本，不带 Relay、Proxy、Data Center 标记。

**广播 IP** 是机房在日本、IP 段却广播自其他地区。日本节点里广播 IP 相当常见，查归属可能显示美国或香港。对流媒体解锁和风控敏感的业务影响直接，有的商家会在条款里明写"不承诺 100% 能访问有特定要求的网站"。

**ISP 住宅 IP / 家宽 IP** 来自日本本地家庭宽带运营商，WHOIS 归属显示的是 IIJ、SoftBank、NTT 这类 ISP。平台风控看到的就是一个普通日本家庭在上网，账号存活率高，Netflix 日区、AbemaTV、U-NEXT 多数情况能过，做跨境电商、社媒运营、AI 平台注册的人最认这个。

Akile 日本线这里要特别提醒一句。公开测评写的是"支持 DNS 解锁日本流媒体"，官方套餐说明也只提到"日本机房支持当地流媒体解锁"。DNS 解锁是商家在解析层面把流媒体域名指到能解锁的节点，跟你拿到的 IP 本身是不是原生，是两回事。Netflix、AbemaTV 这类只看 IP 的平台，DNS 解锁通常有效；银行、支付网关、部分电商看的是 IP 注册属性，DNS 解锁帮不上忙。

所以下单前该问的是这句：这个套餐的 IP 是日本原生，还是广播 IP 加 DNS 解锁？答案会决定它适不适合你的业务。

同价位套餐一款原生一款非原生的情况并不少见。六六云日本软银四款套餐里，前两款标原生 IP，后两款标"非原生、联通优化"，价格都是 ¥48/月，只能靠套餐名和测试 IP 区分。买之前不看这一栏，很容易花了原生的钱拿到广播 IP。

## 参数口径与隐藏成本：标称 2.5Gbps 不等于一直 2.5Gbps

带宽那一栏的数字，实际含义分三种。峰值带宽是理论上限，能不能持续跑看机房负载；共享带宽高峰期会被限速；独享才是稳定值。JPHyper 标的 2.5Gbps 属于峰值口径，日常跑个几百兆是正常表现，别拿它当保底。

流量超了会怎样，各家处理方式不同，这是买之前必须确认的一条。Akile 日本 Pro 系列的处理是超出后限速共享 10Mbps，不停机，同时支持重置流量。DMIT 的两条线正好是两个极端：TYO.Pro 流量耗尽直接暂停服务，TYO.T1 降到 50Mbps 继续跑。同样是"超流量"，一个是断网一个是慢速，对你的业务影响可能完全不同。

BBR 是另一个容易忽略的点。没开 BBR 的机器，标称带宽经常跑不满，尤其是跨运营商的长距离传输。Akile 的测评机显示已启用 BBR，但套餐是否默认开启，下单页面未必写明，开通后自己确认一遍更稳妥。

## 常见问题

**原生 IP 能保证解锁 Netflix 日区吗？**
不能。流媒体平台的 IP 封禁名单是动态更新的，DMIT 这类以原生 IP 为卖点的商家也明确不做书面保证。买之前用测试 IP 跑一遍 IP 属性检测和流媒体检测，比看宣传语靠谱。

**日本和香港到底怎么选？**
看业务面向哪里。日本延迟约 50ms，带宽大、流量多、IP 类型选择丰富；香港延迟 20 到 30ms，但带宽小、价格贵、原生 IP 紧张。面向日本本地和东南亚选日本，纯大陆中转选香港。

**月付还是年付？**
第一次用某家，先月付。线路满不满意、晚高峰稳不稳，跑两周就知道了。确认没问题再转年付锁折扣，年付普遍比月付省一成到三成。

**流量超了会怎样？**
两种模式：限速继续跑，或者直接暂停。Akile 日本 Pro 系列是超出后限速共享 10Mbps 并不停机，支持重置流量；DMIT 的 TYO.Pro 是直接暂停。买之前确认这一条，比看流量数字本身更重要。

**怎么验证买到的 IP 是不是原生？**
拿到机器后跑 IP 属性检测，看归属地是否显示日本、有没有 Proxy 或 Data Center 标记。更省事的办法是下单前找客服要测试 IP，先测再买。
